# Student Performance Analyzer

An interactive academic analytics dashboard built using Python, Pandas, Matplotlib and Streamlit.

## Live Application

The application allows users to upload student data in CSV format and automatically analyze academic performance.

## ✨ Features

- 📂 Upload student data through CSV
- 👩‍🎓 Calculate individual student performance
- 📊 Calculate class average
- 🏆 Identify the top performer
- 📚 Compare subject-wise performance
- 🏅 Generate grades automatically
- 📈 Analyze attendance vs academic performance
- 💡 Generate automatic performance insights
- 👤 View individual student analysis
- 💾 Download analyzed results as CSV

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Streamlit
- GitHub

## 📋 Input Data

The CSV file should contain the following columns:

Example:

Name	Math	Python	DBMS	Attendance
Akshra	85	92	78	91
Rahul	72	68	75	82
Priya	94	89	96	97

## Analysis Performed

The application calculates:

Total marks
Average marks
Grade
Pass/Fail result
Class average
Best-performing subject
Subject needing improvement
Top-performing student
Attendance-performance relationship
## Purpose
The project demonstrates how Python-based data analysis can be transformed into an interactive web application for academic performance monitoring.
